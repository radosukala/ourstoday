# Edition card fonts

Committed so card generation needs no third-party fetch at render time — the
same reason the CSP allows no external origin in the browser.

| File | Family | License |
| --- | --- | --- |
| `ArchivoBlack-Regular.ttf` | Archivo Black (Omnibus-Type) | SIL Open Font License 1.1 |
| `IBMPlexMono-Regular.ttf` | IBM Plex Mono (IBM) | SIL Open Font License 1.1 |
| `IBMPlexMono-Bold.ttf` | IBM Plex Mono (IBM) | SIL Open Font License 1.1 |

Obtained from the Google Fonts repository (`google/fonts`, `ofl/` tree). The
OFL permits redistribution and bundling; the fonts are not sold, and no
Reserved Font Name is used to name a derivative. Archivo Black stands in for
the site's heavy system grotesk, IBM Plex Mono for its system mono stack —
the browser keeps using system fonts; these exist only inside generated
images.
